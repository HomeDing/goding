About GoDing

The project

GoDing is a Go-based HomeDing device implementation for Windows PCs and laptops. It brings local, REST and JSON based device control to a Windows computer without requiring a cloud service or a central server.

GoDing is part of the HomeDing ecosystem, an open network protocol and collection of device implementations for local automation.

The application

GoDing currently provides:

  • A web server for the user interface and REST API.
  • A MIDI receiver for faders, buttons, and other MIDI messages.
  • A volume controller for Windows audio endpoints and applications.
  • Configuration and action handling for HomeDing-compatible control.

The application is experimental and is being developed incrementally around Go's standard library and concurrency features.
